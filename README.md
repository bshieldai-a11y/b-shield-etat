# État du service B-SHIELD ONE

Page d'état publique de B-SHIELD ONE, hébergée **hors de** l'application, pour rester en ligne même si B-SHIELD ne répond pas.

- `index.html` : la page. Elle vérifie en direct, depuis le navigateur du visiteur, si B-SHIELD répond.
- `etat.json` : le message d'incident écrit par l'équipe (vide quand tout va bien).

Ce dépôt ne contient **aucune donnée** de client, aucun code de B-SHIELD et aucun secret.
